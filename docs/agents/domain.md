# 领域文档

本仓库采用单一上下文（single-context）布局：

- 仓库根目录的 `GLOSSARY.md`：领域术语。
- `docs/adr/`：架构决策记录。

## 探索前读取

探索代码前，读取已有的 `GLOSSARY.md`，
以及 `docs/adr/` 中与当前工作相关的决策记录。

文件或目录不存在时，直接继续工作。
术语或决策明确后，再由 domain-modeling 技能按需创建。

## 使用术语

任务标题、方案、假设和测试名称中的领域概念，
使用词汇表定义的术语。

所需概念尚未收录时，先确认是否符合项目现有用语；
确有缺口时，记录下来供 domain-modeling 处理。

## 决策冲突

输出与已有 ADR 冲突时，明确指出对应 ADR，
并说明重新讨论该决策的理由。
