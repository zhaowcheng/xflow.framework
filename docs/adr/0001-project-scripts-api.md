# 项目声明脚本入口，框架统一处理脚本执行

项目在 `scripts/__init__.py` 中定义继承框架基类的 `Scripts`，集中维护 `DEPS` 和可自定义名称、参数的脚本入口；框架基类通过 `__exec` 统一处理依赖解析、上传和执行，`Node` 提供节点基础能力。相较于继续由 `Node.exec_script` 读取独立声明文件，这一选择让脚本的调用约定和依赖声明集中在项目的同一个接口中，代价是项目需要维护脚本入口方法并迁移原有调用；双下划线的名字改写还要求框架基类和项目子类在定义中都名为 `Scripts`。用户已逐项确认这一职责划分、由 Pipeline 自动加载并实例化项目 Scripts、保留参数字符串、强制提供项目 Scripts、无需类型提示配置，以及一次切换移除旧接口；完整方案等待收尾确认，记录见 `.scratch/script-dependencies/design-notes.md`。
